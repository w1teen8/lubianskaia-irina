# Ірина Люб'янська — Студія краси

Преміальний багатосторінковий сайт студії краси Ірини Люб'янської
(епіляція, депіляція, шугаринг, ламінування вій, корекція та
фарбування брів) у Боярці.

## Стек

- React + TypeScript + Vite
- React Router (HashRouter — для сумісності з GitHub Pages)
- Tailwind CSS
- Framer Motion

## Розробка

```bash
npm install
npm run dev
```

## Збірка та деплой

Сайт автоматично збирається та публікується на GitHub Pages через
GitHub Actions (`.github/workflows/deploy.yml`) при кожному push у
`master`.

Локальна збірка:

```bash
npm run build
```
